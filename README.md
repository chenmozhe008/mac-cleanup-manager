# Mac 清理管家

版本 1.0.3 · 作者 @沉默者之二 · 反馈 327529709@qq.com · 更新记录见 [CHANGELOG.md](CHANGELOG.md)

原生 macOS 空间扫描与逐项缓存清理工具。项目、资源库和大文件只显示占用与 Finder 定位；识别为可再生的缓存才可加入待清理清单。执行前集中核对准确路径；应用不会清空废纸篓。

## 怎么用

1. 左栏选一个扫描位置：**快速扫描**（只看常见缓存，几秒）、**完整扫描**（整个用户目录，几分钟，能找出大文件和剪辑缓存），或自己添加的文件夹。点位置只切换、显示上次结果，按右上「重新扫描 / 开始扫描」才会扫。
2. 结果按 **可清理缓存 / 剪辑与设计软件 / 微信与企业微信 / 需要判断 / 大文件与工程** 分类。只有缓存能勾选（点整行即选中）；其余带锁，只提示占用和在原软件里怎么处理。
3. 底部汇总已选大小，点 **移入废纸篓…** 核对路径后确认。废纸篓里的文件仍可恢复；清空废纸篓由你自己决定。

个人安装位置：`~/Applications/Mac 清理管家.app`。扫描结果不需要上传到云端。

## 运行

使用要求：macOS 14 Sonoma 及以上，Apple 芯片（M1 及更新，当前只构建 arm64）；macOS 26 起界面显示液态玻璃效果，更早系统用普通磨砂效果。

开发需要 Xcode 或 Swift 命令行工具链。

```sh
./script/build_and_run.sh
```

构建好的 App 位于 `dist/Mac 清理管家.app`。构建脚本使用本机 Apple Development 证书签名；可通过 `CODESIGN_IDENTITY` 指定证书。保持同一签名身份与安装路径，有助于 macOS 在更新后继续识别此前授权的 App。`./script/build_and_run.sh --verify` 会构建、启动并检查进程。运行 `swift test` 验证分类和保护规则。

## 当前能力（2026-10-21 更新）

- 深色品牌界面：欢迎页、扫描中「边扫边发现」实时列表、结果页环形图 + 分类卡；左栏记住选过的文件夹，启动直接显示上次结果。
- 剪辑与设计软件单独成类：AE 磁盘/媒体缓存可在这里清；Final Cut 渲染文件、达芬奇 CacheClip 只提示并给出在软件里的清理步骤。
- 微信、企业微信只读统计占用，超过 2 GB 提醒，并给分步清理说明；本应用不删除任何聊天数据（需开启「完全磁盘访问」才能读到）。

## 当前能力

- 扫描个人文件夹、已挂载外接盘或手选文件夹；扫描只读，不跨卷跟随符号链接。
- 识别 Final Cut 资源库、AE/Blender/DaVinci 等工程文件及大文件；工程和应用数据只提示占用并提供 Finder 定位。
- 扫描结果按 A 可再生缓存、B 应用缓存、C 人工判断分级；只有 A/B 缓存可勾选并在核对路径后移入废纸篓。
- 快速扫描 `~/Library/Caches` 的可审阅子目录，以及 Codex 运行时、uv、pip、npm、应用更新包、AE 磁盘缓存、Adobe 媒体缓存和 Blender 应用缓存等已识别位置；完整扫描还识别 Swift `.build`、Python 缓存和 Next.js 缓存。`node_modules` 属于 C 类，只提示。
- 闪电说录音只统计超过 15 天的旧录音，归 C 类提示，应用不自动删除。Codex 和闪电说数据目录只进入明确允许扫描的子目录；录音工作台、Xcode、聊天数据和技能备份保持保护。
- 完整扫描遇到 Final Cut 资源库内的 `Render Files`、达芬奇 `CacheClip` 时只提示大小与原软件处理办法。Figma 本地数据和 Blender 设置只计入占用，不作为可清理缓存。
- 保护常见聊天、凭据、Codex 数据、录音工作台数据与 Xcode 数据目录。保护规则目前在 `SafetyPolicy.swift`，后续会做成用户可管理的设置。
- 清理前复核路径、类型与扫描时的文件身份，再调用 macOS 废纸篓接口。

## 当前限制

- 快速扫描只覆盖已识别位置，不代表整盘可释放空间。扫描大小是逻辑文件大小；APFS clone、快照和可清除空间可能使其与实际可释放量不同。
- 尚未做工程迁移、重复文件判断、Final Cut 生成媒体的原软件内自动处理和多卷容量趋势。
- Homebrew 下载缓存可审阅，旧版本仍需在 Homebrew 中预览并操作；应用不运行 `brew cleanup`。完整扫描会提示超过 100 MB 的 DMG/PKG 安装包，但不会据此断定“旧版”或提供清理按钮。后台每日监控仍由现有 `clean-disk` skill 的监控脚本负责，App 内只在磁盘可用低于 6 GB 时显示提醒。当前 App 仍不是该 skill 的完整替代。
- 扫描范围由当前 macOS 文件访问权限决定；未授权、受保护及符号链接目录会计入未读取数量。“已计入文件”只统计实际遍历到的文件，不等于整个卷的占用。
- macOS 的“文件与文件夹”及“完全磁盘访问”权限必须由用户在系统中授权；应用不能自行授予。稳定签名无法保证系统永不询问，换证书、换 App 身份或撤销权限后仍可能再次询问。
- 这是使用本机 Apple Development 证书签名的本地开发构建，尚未公证；在另一台 Mac 上分发前需要正式的分发签名与公证。
